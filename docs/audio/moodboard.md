# 音频情绪板（Phase 0 同期工作 · 01 §14）

> 所有声音都由 `tools/audio/render.ts` 离线合成（无第三方采样，无授权问题），`pnpm assets:audio` 重新生成。本文件是方向说明与试听清单；**方向确认需要音频负责人试听签字**（见文末）。

## 1. 方向

| 维度 | 方向 | 合成实现 |
|---|---|---|
| 消除 | 马林巴 / 卡林巴：短、圆、木质 | `marimba()`：基频 + 3.93 倍与 9.9 倍泛音，快速衰减 |
| 露台 | 木吉他 + 轻弦乐：慢、暖、留白 | `pluck()`（Karplus-Strong）+ 长起音正弦垫 |
| 点缀 | 玻璃风铃：高、透、稀疏 | 每 4 小节一次三音高位正弦 |
| 环境 | 晨间鸟鸣、夜间虫鸣、浇水声 | `ambience()`：晨为上下滑音短鸣，暮为 35 Hz 调制的高频短脉冲；`water` 为滤波噪声 |
| 级联 | 五声音阶逐层上行（C D E G A C′ D′ E′），最多 8 层 | `CASCADE_STEPS` + `cascadeRate()`，上限读 `tunables.audio.cascadeMaxSteps` |

## 2. 三个代表性小样

在 `public/audio/sfx.json` 中按起点毫秒与时长定位，可用 `ffplay -ss <起点/1000> -t <时长/1000> public/audio/sfx.mp3` 试听。

| 小样 | 精灵 id | 用途 | 听感目标 |
|---|---|---|---|
| 交换 | `swap` | 每次交换 | 轻、干净，重复一百次也不烦 |
| 熟果收割 | `harvest2` | 熟作物被收割（级联时升调） | 圆润、有“收获”的满足感，连响时形成上行旋律 |
| 镰刀 | `sickle` | 横 / 竖镰刀激活 | 一道清脆的“划过”，比收割更亮但不刺耳 |
