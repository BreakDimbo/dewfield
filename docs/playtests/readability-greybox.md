## 结论（自评）

| 规则 | 结果 | 备注 |
|---|---|---|
| RD-1 剪影唯一 | 通过（熟/青）；芽需复核 | 倒锥+叶簇 / 扁球+星萼 / 高柱+包叶 / 弯水滴 / 三球簇在灰度下可分；芽（0.55 倍）中茄子与番茄在远排偏小，正式测试重点看 |
| RD-2 三重编码 | 通过 | 缩放 0.55/0.8/1.0；青降饱和 35%、芽再向嫩绿偏 22%；熟为金色碟沿（灰度下为亮环） |
| RD-3 不透明 | 通过 | 作物与碟子不透明；透明只用于玻璃（单层）与叠加粒子/光晕 |
| RD-4 特效标记 | 通过（已加大） | 镰刀：亚麻徽章 + 刃 + 双向箭头（横/竖）；晨露珠：水滴 + 光环；蜂群独立模型。预检后把徽章放大到 1.2、箭头加大、蜂群放大到 1.4 |
| RD-5 预演层级 | 通过 | 收割白环 + 底光 > 产出珠（交货珠更大）> 生长箭头（嫩绿/雾蓝）> 特效幽灵六边环 |
