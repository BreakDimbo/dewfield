# 《晨露田园》Dewfield — 完整方案 v2（双核修订版）

一款网页软 3D 种田 × 消消乐。
局内保住「算到了，还炸得比想的好看」；局外保住「这块地因为我照料过，更像我的了」。

## 1. 一句话定位
你在一座会过夜的玻璃露台上种田：日常是照看与变美；接市集委托时，整块田变成可滑动的立体棋盘——消除即收割与连锁，打完带回露水与记忆，田不会被关卡清空。

- 平台：现代浏览器（桌面优先，平板友好）
- 单次委托：2–4 分钟
- 气质：清爽、照料、微成就、收藏欲；精品独立感

## 2. 双核（设计不可妥协）
| 核 | 玩家要感到 | 系统落点 |
|---|---|---|
| 消消乐 | 可读预演、低成本试错、连锁惊喜 | 局内交换、特效、掉落、丰收演出 |
| 种田 | 时间期待、照料、家园归属 | 持久露台、过夜生长、少量高价值照料、装饰积累 |

原则：消除不是挂在农场皮上的小游戏；露台也不是三消的选关地图。二者共用同一块地，时间尺度不同。

## 3. 结构：枢纽露台 + 市集委托
启幕 → 露台枢纽（持久家园）
- 照看：浇垄 / 蜂箱 / 看过夜变化
- 装修 / 图鉴 / 料理
- 今日市集 → 对局（同一块田的专注模式）→ 结算写回枢纽

- 露台：永久存档的 3D 家园，默认体验
- 委托：有限步数三消，是「今天帮市集忙一把」
- 对局棋盘由当前露台状态生成；结束写回，不整盘销毁记忆

## 4. 核心玩法

### 4.1 棋盘（局内）
- MVP：7×7，四向交换
- 每格：3D 作物 + 土壤碟；固定 3/4 俯视，轻微视差
- 轻度坡向：新芽从低处拱出；熟果短距软滚动再对齐

### 4.2 生长态（局内：可读与收获）
- 芽：半透明；重组，不进订单篮
- 青：可连锁；产露水
- 熟：计入委托与仓库
- 局内不做每步全体微生长；催熟只来自特效与露台被动

### 4.3 特效
- 4连→镰刀；5连→蜂群；L/T→晨露珠；双特效碰撞升级

### 4.4 委托流程
- 每局通常 1 个主订单（可选 1 个星星小目标）
- 步数约 20–28
- 失败不扣能力，最多少一张加分小单

### 4.5 局外：过夜与照料
- 过夜：再进时未收边角微熟、肥力冒新芽倾向、天空随时段变；不卡进度
- 照料：浇垄/蜂箱等，每天次数有限，改写下一场生成规则与被动

### 4.6 料理
- 枢纽料理台；解锁装饰/皮肤/被动；不做关卡必做演奏题

## 5. 长线与经济
- 季节四套；装修被动+观感；图鉴；每日 1 主委托 + 最多 1 加分小单
- 露珠 / 木料·玻璃

## 6. 田的「被记住」
禁止无记忆整盘随机重置。保留：作物权重、装饰与照料被动、上一局边角色/肥力、季节时段。

## 7. 美术与 UI
柔光玻璃、陶土亚麻、克制植物色。色板：#F7F1E8 / #5B8F6B / #D9A39A / #A7C4D0 / #2C2A28。枢纽海报感；对局保可读。

## 8. 进度
教程 3 场；约 15 委托池；家园里程碑；星级不锁死主线。石盆/雨雾日为氛围规则，非惩罚降能力。

## 9. 技术
Vite + React + TS；Three.js + R3F + Drei；Zustand（棋盘纯逻辑与 Three 分离）；Howler；localStorage。
存档：Homestead 为主，Run 为会话；结算差分写回。

## 10. MVP
持久露台+过夜表现；每日有限照料；7×7/6作物/三态/镰刀水壶；委托池+每局1主单；状态生成写回；UI+存档。

## 11. 成功标准
1. 90秒内打出4连特效
2. 前10分钟感到「要回露台看看/浇一下」
3. 露台可当海报；对局清晰
4. 外评接近「消除是在养自己的田」

## 12. v1→v2 变更
关卡主轴→持久露台+委托；每步微生长→过夜+照料；多订单→1主单；惩罚→氛围；整盘重置→记忆；20关→委托池+里程碑。
