# 桜ヶ丘ふれあい农园

在日式小镇里第一人称走动种树的网页 3D 游戏：8 块田，六种树，按游戏内日夜生长；消消乐只在种子摊上产出种子和农具。

代码、运行方法和玩法说明都在 [`sakura-farm/`](sakura-farm/README.md)。场景基于 [Kenton-GMI/sakuragaoka-station](https://github.com/Kenton-GMI/sakuragaoka-station)（MIT，见 `sakura-farm/NOTICE.md`）。

```bash
cd sakura-farm
npm install
npm start
```
