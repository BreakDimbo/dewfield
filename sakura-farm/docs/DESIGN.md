# 桜ヶ丘ふれあい農園 — 设计文档

在《桜ヶ丘駅》小镇（见 `NOTICE.md`）里种树的第一人称种田游戏。场景、渲染、模块契约沿用原项目（`docs/DESIGN-sakuragaoka.md`）；本文件只写新增的玩法与模块。

## 1. 一句话

走到河堤下的农园，用锄头松土、播下种子、每天浇水，把樱、梅、红叶、柿、蜜柑、松养成大树；种子和农具只从种子摊上的消消乐里来。

## 2. 核心循环

```
早晨 6:00 ─► 种子摊（消消乐，每天 3 张券）─► 种子 + 农具
   ▲                                               │
   │                                               ▼
夜里睡觉（小屋）◄── 收获花/果/叶 ◄── 农园：松土 → 播种 → 浇水 / 施肥 / 修剪
   │         （3 个收获物 = 1 张额外券；记入图鉴）
   └─ 过夜：当天浇过水的树长一天；雨天自动浇水；券恢复为 3 张
```

- 消消乐**只**产出种子和农具，不产出金钱或其他资源。
- 种田是独立玩法：在 3D 小镇里第一人称走动，对准田块操作。
- 目标：六种树都长成成树（图鉴全满）。没有失败、不会枯死；忘记浇水只是不长。

## 3. 时间

- 游戏内一天从 6:00 到 24:00，真实时间约 12 分钟（`CLOCK.minutesPerSecond = 1.5`）。
- 17:00 以后可以在农具小屋睡觉；到 24:00 自动回家睡觉。睡觉 = 结算过夜 → 次日 6:00。
- 光照随时间变化：清晨偏冷、正午明亮、傍晚橙色、夜里蓝紫（路灯和屋内亮起）。

## 4. 树种（`src/game/data.js` 为准）

| id | 名称 | 各阶段所需浇水天数（芽/苗木/小树/成树） | 成树产出 | 备注 |
|---|---|---|---|---|
| sakura | 桜 | 1 / 2 / 2 / 3 | 桜の花びら | |
| ume | 梅 | 1 / 2 / 2 / 2 | 梅の実 | |
| momiji | 紅葉 | 1 / 2 / 3 / 3 | 紅葉の葉 | 春里就是红叶的品种（野村紅葉） |
| kaki | 柿 | 1 / 2 / 3 / 3 | 柿 | 消消乐里较稀有 |
| mikan | 蜜柑 | 1 / 2 / 3 / 4 | 蜜柑 | 消消乐里较稀有 |
| matsu | 松 | 1 / 3 / 3 / 4 | 松ぼっくり | 小树必须修剪一次才会长成成树；最稀有 |

阶段：`0 空地` → `1 松过的土` → `2 种子`（播种后）→ `3 芽` → `4 苗木` → `5 小树` → `6 成树`。
表中的天数是从 种子→芽、芽→苗木、苗木→小树、小树→成树 各需要的“浇过水的夜晚”数。

## 5. 农具与操作

| 快捷栏 | 物品 | 来源 | 作用 |
|---|---|---|---|
| 1 | 鍬（锄头） | 初始自带，不消耗 | 空地 → 松过的土；对成树以外的树没有作用 |
| 2 | 種袋（种子袋） | 消消乐 | 在松过的土上播下当前选中的树种（`R` 或滚轮切换树种） |
| 3 | じょうろ（水壶） | 消消乐，按“水”计次 | 给当天还没浇水的田浇水，消耗 1 次 |
| 4 | 肥料 | 消消乐 | 下一次过夜时这块田多长 1 天 |
| 5 | 剪定ばさみ（剪刀） | 消消乐，按次数 | 松的小树：允许长成成树；其他成树：下次收获 +1 |
| 6 | かご（篮子） | 初始自带 | 收获成树结出的产物 |

- 操作：准星对准田块，左键（或 `E`）执行手中物品的动作；屏幕下方提示当前能做什么、为什么不能做。数字键 `1`–`6` 切换快捷栏，`Shift+1`–`6` 瞬移到各地点。飞行模式（`F`）只在 `?fly` 调试参数下可用。
- 每块田每天只需要浇一次水；已浇水的土颜色变深。
- 成树每 2 天结一次（需要结果前一晚浇过水），结果后树上可见花/果/红叶变多。

## 6. 消消乐（种子摊「種の屋台」）

- 7×7 棋盘，6 种棋子 = 6 个树种的种子图案；稀有树种棋子出现得少：权重 桜 4 / 梅 4 / 紅葉 4 / 柿 3 / 蜜柑 3 / 松 2。
- 每局 15 步；拖动或点选交换相邻两格，必须形成三连。
- 消掉的普通棋子按树种累积“种子点数”；每满 `seedPoints` 点得到 1 颗该树种的种子（普通 6、柿/蜜柑 8、松 10）。
- 特殊棋子（生成在交换落点）：
  - 4 连 → **じょうろ棋子**：引爆时清一整行（横 4 连）或一整列（竖 4 连），并得到 **水 ×2**。
  - L/T 形 → **肥料棋子**：引爆时清 3×3，并得到 **肥料 ×1**。
  - 5 连 → **剪刀棋子**：与相邻棋子交换即引爆，清除棋盘上所有该种棋子，并得到 **剪刀 ×1**。
- 连锁：消除后下落补充，形成的新三连继续消除；没有可走步时自动洗牌。
- 一局结束显示收获清单并写入背包。每天 6:00 恢复为 3 张券；3 个收获物可以换 1 张额外的券。

## 7. 农园布局（`src/world/layout.js` → `FARM`）

- 位置：原北侧第二排西段住宅区（`N2W`，x −85…−15.5，z −83.5…−72.7），南临住宅小巷 R6（z = −71），北靠河堤和堤上的樱花树。
- 8 块田，每块 5.5 × 5.5 m，间隔 1.5 m 草径，一排排开（x −76 … −27，中心 z = −78.4）；前面是一条砂石步道。
- 东端：农具小屋（睡觉、存档）、种子摊（消消乐）、入口的木牌「桜ヶ丘ふれあい農園」。

## 8. 代码结构

```
src/game/                 纯逻辑，不依赖 three / DOM，可在 node 里测试
  data.js                 树种、农具、时钟与消消乐常数
  rng.js                  可序列化的种子随机数
  state.js                新游戏、存档序列化与校验
  farm.js                 田块操作与过夜结算（纯函数：state → { state, events }）
  clock.js                游戏内时间、光照阶段
  match3/engine.js        消消乐规则：生成、匹配、特殊棋子、下落、补充、洗牌
  match3/rewards.js       消除结果 → 种子点数与农具
src/world/farm.js         世界模块：田块、步道、围栏、小屋、种子摊、木牌（静态）
src/world/trees.js        世界模块：田里的树（动态，按存档状态重建）
src/ui/                   HUD、快捷栏、交互提示、消消乐界面（DOM + canvas）
tests/*.test.mjs          node --test
```

模块契约与原项目一致：世界模块导出 `build(ctx)`，静态物体用 `ctx.addStatic`，会变化的用 `ctx.add`；游戏状态通过 `ctx.services.game` 共享。
